# 科學運算邏輯重新設定（文獻依據版）

本文盤點《氣候韌性實驗室》現行模擬引擎（`advanceTurn.ts`、`apiClients.ts`）的科學問題，並依國際權威標準與同儕審查文獻提出重設方案。目標：讓每一條公式都能對學生與審查者說明「為什麼是這個係數、出處在哪」。

---

## 1. 現行模型的核心問題

| 區塊 | 現行做法 | 問題 |
|---|---|---|
| 風險合成 | 熱/洪/空污風險 = 一堆手調線性權重相加 | 沒有對應任何風險框架；係數無出處、無單位、不可解釋 |
| 熱風險 | `imperviousness*24 − canopyCover*24 − coolingAccess*18 …` | 權重憑感覺；與實證的 UHI 升溫率脫鉤 |
| 空污風險 | `12 + pm25*2.1`（線性） | AQI 本質是分段折線（breakpoint），不是線性；無法對齊任何國家標準 |
| 熱浪定義 | 日高溫 ≥ 35°C、熱夜 ≥ 26°C | 與台灣中央氣象署（CWA）官方門檻不符（高溫 36°C / 38°C；熱夜慣用 ≥25°C） |
| 洪水風險 | 不透水面 × 22 等線性項 | 與水文學逕流概念（逕流係數 / SCS-CN）脫鉤 |
| SDG 綜合分數 | 9 項手調權重相加 | 權重無依據；建議改為透明、可說明的標準化加權 |

核心病灶：**模型把「氣候訊號」直接乘上魔術數字**，而不是先轉成有物理/流行病學意義的中間量（升溫量、AQI、逕流量、超額死亡風險），再合成風險。

---

## 2. 採用的權威框架與文獻

### 2.1 風險三要素（IPCC AR6）
IPCC 第六次評估報告把風險定義為三者交互作用：

$$\text{Risk} = f(\text{Hazard},\ \text{Exposure},\ \text{Vulnerability})$$

- **Hazard 危害**：氣候事件本身（熱浪、強降雨、高溫日數）。
- **Exposure 暴露**：暴露在危害下的人口、資產（街區人口、都市化）。
- **Vulnerability 脆弱度**：易受傷害且調適能力不足的程度（綠覆率、降溫設施、公平）。

→ 重設後每個風險指標都顯式拆成「危害 × 暴露 × 脆弱度」三欄，教學上可直接對應 CER/系統思考。

### 2.2 都市熱島升溫率（實證係數）
同儕審查研究給出可直接用的線性靈敏度（街區尺度、夏季）：

- 樹冠覆蓋每 **+10% → 氣溫約 −2.5°C**
- 不透水面每 **+10% → 氣溫約 +1.87°C**

來源：Ziter et al., *PNAS* 2019, 116(15):7575（樹冠×不透水交互作用、街區尺度升溫率）；Manoli et al., *Nature* 2019, 573:55（UHI 量值由氣候與人口解釋、蒸散機制）。
→ 取代原本 `*24` 的魔術數字，改用「以 °C 為單位的 UHI 升溫量」，再轉成熱危害分數。

### 2.3 高溫/熱夜門檻（台灣 CWA 官方）
- 高溫資訊：日最高溫 **≥ 36°C**（黃燈/高溫提醒）；**≥ 38°C** 或連續 3 日 ≥36°C（橙/紅燈）。
- 熱夜（tropical night）：採用日最低溫 **≥ 25°C**（WMO 全球定義為 ≥20°C，亞熱帶都市常用 25°C；CWA 另有「超級熱夜」28°C）。
→ `apiClients.ts` 的 `HEATWAVE_MAX_TEMP_C` 由 35 改 36；`TROPICAL_NIGHT_MIN_TEMP_C` 由 26 改 25，並在 UI 標註定義出處。

### 2.4 空氣品質：US EPA PM2.5 AQI 分段折線（2024 更新）
AQI 是分段線性內插，2024/5 生效的 PM2.5 24 小時 breakpoint：

| AQI 類別 | AQI 上下界 | PM2.5 (µg/m³) 下界–上界 |
|---|---|---|
| Good | 0–50 | 0.0 – 9.0 |
| Moderate | 51–100 | 9.1 – 35.4 |
| USG | 101–150 | 35.5 – 55.4 |
| Unhealthy | 151–200 | 55.5 – 125.4 |
| Very Unhealthy | 201–300 | 125.5 – 225.4 |
| Hazardous | 301–500 | 225.5 – 325.4 |

內插公式（EPA 官方）：
$$I = \frac{I_{hi}-I_{lo}}{C_{hi}-C_{lo}}(C - C_{lo}) + I_{lo}$$

→ 以真正的 AQI（0–500）取代 `pm25*2.1`，再線性映射到 0–100 空污風險分數；同時保留 WHO 2021 年指引（年均 5、24h 15 µg/m³）作為「健康目標線」。

### 2.5 洪水：逕流係數 / SCS-CN 概念
都市淹水危害的一階近似是「降雨 × 逕流係數」。不透水面比例 `imp` 與逕流係數 `C` 近似正相關（合理化公式 Rational Method，C 從綠地 ~0.1 到全鋪面 ~0.9）：

$$C \approx 0.05 + 0.85 \cdot \text{imperviousness}$$

危害再以暴雨日數與雨量異常放大，脆弱度由防洪設施 `floodDefense` 與高程 `elevationM` 折減。
→ 取代原本的線性魔術項，物理意義是「有多少雨變成地表逕流」。

### 2.6 SDG 綜合分數：透明標準化加權
維持加權平均，但（a）權重寫成具名常數並在文件列出理由；（b）所有子分數先標準化到 0–100 同向（風險取 `100 − risk`）；（c）對齊涵蓋的 SDG（3,6,7,9,10,11,12,13,15）。建議預設等權再微調，避免「看起來精確其實任意」。

## 3. 重設後的計算管線（每街區→全市）

```
氣候訊號(API)
  → 危害層 Hazard  (UHI升溫°C、AQI、逕流量、暴雨指數)   ← 文獻係數
  → 暴露層 Exposure (人口、都市化比、街區類型)
  → 脆弱度層 Vulnerability (綠覆、降溫、防洪、公平、調適)
  → Risk = Hazard × Exposure修正 × Vulnerability修正  (IPCC AR6)
  → 標準化 0–100
  → 人口加權彙整為全市指標
  → 健康(流行病學熱-死亡關係) / SDG 綜合分數
```

關鍵中間量（會在 UI 與 log 顯示，供 CER 舉證）：
- `uhiDeltaC`：街區相對基準的都市熱島升溫（°C）
- `aqiPm25`：對齊 EPA 的 0–500 AQI
- `runoffCoefficient`：逕流係數 0–1
- `heatHazard / floodHazard / airHazard`：0–100 危害分數

## 4. 對 API 引用的修正

1. **熱浪/熱夜門檻**對齊 CWA（36°C / 25°C），UI 標註定義來源。
2. **NASA POWER 太陽輻射**單位確認為 kWh/m²/day（`ALLSKY_SFC_SW_DWN` 原始為 kWh/m²/day），目前範圍 0–12 合理，保留。
3. **OpenAQ v3** 已正確讀 `pm25`；改為餵進 EPA AQI 函式而非直接乘係數。
4. **World Bank** 人口/都市化比正確；建議加 SP.URB.GROW（都市成長率）作為暴露趨勢（選用）。
5. 所有 API 缺值時的本地基準（台北）保留，並在來源面板顯示「實測 vs 補值」以教資料不確定性。

## 5. 實作順序（建議）

1. 新增 `src/game/simulation/scienceModel.ts`：純函式，輸出上述中間量（可單元測試、可被試題引用）。
2. 重寫 `advanceTurn.ts` 的 `getClimateIndicatorScores` / `recalculateDistrict` 改呼叫 `scienceModel`。
3. 調整 `apiClients.ts` 門檻常數 + 接 AQI 函式。
4. 在 HUD 與 log 顯示中間量，讓政策效果可被「資料舉證」。
5. 加 `scienceModel.test.ts`：用文獻數值驗證（如 canopy +10% 應使 UHI 約 −2.5°C）。

> 註：以上係數為教學模型的一階近似，目的是「可解釋、方向正確、與權威門檻一致」，非工程級水文/空品模式。此定位會寫進教師說明，符合科學建模教學中「理想模型→真實模型」的進程。
