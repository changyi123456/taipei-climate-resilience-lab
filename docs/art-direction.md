# 美術與 UI 方向：台北韌性指揮桌

## 玩家幻想與鏡頭

玩家是跨領域城市科學委員會的決策者，透過台北立體沙盤進行「觀察 → 假設 → 審議政策 → 比較 → 舉證」。預設採 45° 正交城市模型鏡頭；桌面、平板與手機瀏覽器皆須能完整操作。

## 形狀與辨識

- 城市採清楚、略帶模型感的 stylized PBR，不追求照片寫實。
- 六種街區必須以天際線與地表用途辨識，而不只靠顏色：港區貨櫃與岸吊、核心高樓、河岸住宅與濕地、工業煙囪、花園住宅、山坡森林。
- 政策結果必須成為世界中的物件：樹、太陽能板、透水鋪面、滯洪水體與避難設施。
- 高飽和與最高亮度只留給事件警示、選取與政策落地回饋。

## 色彩與資料圖層

- 基底：深海軍藍／青綠指揮桌，搭配日光城市，不採全畫面霓虹。
- 成功：`#72d39d`；警示：`#f0b84c`；危險：`#f0785f`；資訊：`#62c6e7`。
- 定量圖層使用 Viridis 類亮度單調色階，必須同時顯示圖例、數值或單位；不能只用紅綠區分。
- 災害 VFX 必須保留地格、選取外框與 HUD 可讀性。

## UI 層級

- 頂部：年份、章節、預算、SDG 與三個主要風險。
- 左側：章節進度、目標與事件時間線。
- 右側：當前街區、風險、顧問觀點。
- 底部：資料圖層、政策桌與下一年。
- 主要文字至少 14px；互動目標至少 40px；所有對話框具鍵盤焦點與 Escape 返回。

## 動畫與回饋

- 政策：確認投資 → 地表轉換 → 指標 delta → 淡出後果。
- 災害：預警 → 主事件 → 衝擊 → 餘波；碰撞與數值不依賴裝飾粒子。
- 遵循 `prefers-reduced-motion`；年度演出可跳過；省電畫質關閉全螢幕後製與動態陰影。

## Web 品質預算

| 項目 | 省電 | 精緻 |
| --- | --- | --- |
| 目標 FPS | 穩定 30 | 60 |
| 像素比上限 | 1.0 | 1.5 |
| 動態陰影 | 關 | 一盞主光 |
| 全螢幕後製 | 關 | Bloom + color grade |
| 主要保留 | 輪廓、圖層、選取、政策回饋 | 完整氣氛與事件層 |

正式 GLB 資產加入前必須驗證 glTF、記錄來源與授權，並以實際瀏覽器畫面決定材質、貼圖和 LOD 預算。
