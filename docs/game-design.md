# 氣候韌性實驗室

## 定位

《氣候韌性實驗室》是一款 2.5D/3D 科學教育策略模擬遊戲。學生扮演城市科學委員會，在氣候壓力、公共健康、社會公平、預算限制與永續發展目標之間做決策。

這款遊戲的核心不是背誦永續發展目標，而是練習系統思考：同一項政策可能同時影響熱風險、洪水風險、空氣品質、健康、公平、能源安全、生物多樣性與公共信任。

## 玩家身分

玩家是沿海城市的首席科學顧問。每一年都會出現新的氣候壓力，例如熱浪、颱風強降雨、空氣污染、尖峰用電或預算審查。玩家必須選擇地區層級或全市層級的調適政策，並觀察城市模型的變化。

## 主要操作

- 檢查不同城市地區。
- 比較熱風險、洪水風險、空污風險、公共健康、公平與韌性。
- 將有限預算投入氣候調適政策。
- 推進年份，觀察政策與氣候壓力造成的連鎖變化。
- 用資料證據說明政策成效。

## 核心循環

1. 回合開始時，系統給出氣候壓力與任務目標。
2. 玩家選擇地區或全市政策。
3. 模擬系統套用政策效果。
4. 城市風險重新計算。
5. 3D 場景更新熱霧、淹水覆蓋、綠化、建物色彩與選取狀態。
6. 玩家進入下一年，收到年度結算與任務目標進度。

## 第一個可玩關卡：任務 01「熱浪警戒」

玩家目標：在四個回合內讓城市撐過潮濕熱穹，同時保護健康、公平與預算。

任務目標：

- 熱風險 <= 52。
- 公共健康 >= 66。
- 公平 >= 58。
- 熱浪應對政策 >= 2。
- 預算 >= 10 百萬。

目前實作內容：

- 2.5D/3D Three.js 城市沙盤。
- 六個具有不同風險輪廓的地區。
- 八張政策卡。
- 四回合任務時鐘。
- 開場任務簡報。
- 政策效果預覽。
- 每次氣候壓力事件後的年度結算。
- 勝敗任務評估。
- 具備離線備援的氣候資料轉接器。
- 地區檢查器與永續分數回饋。
