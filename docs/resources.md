# GitHub 與 API 資源

| 資源 | 在本專案中的用途 | 授權備註 |
| --- | --- | --- |
| [Three.js](https://github.com/mrdoob/three.js/) | 主要 2.5D/3D WebGL 渲染器，負責相機、燈光、材質、後製、GLB 載入。 | MIT |
| [Vite](https://github.com/vitejs/vite) | TypeScript 網頁遊戲開發伺服器與建置流程。 | MIT |
| [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) | 未來可加入真實城市地圖、GIS 圖磚與地區邊界。 | BSD-3-Clause |
| [Mesa](https://github.com/mesa/mesa) | 未來可作為居民、通勤、健康暴露與政策擴散的 agent-based 模擬後端。 | Apache-2.0 |
| [Godot](https://github.com/godotengine/godot) | 若未來要從瀏覽器移植到完整桌機/行動遊戲，可作為替代引擎。 | MIT |
| [A-Frame](https://github.com/aframevr/aframe) | 若未來需要 WebXR/VR 課堂模式，可作為瀏覽器沉浸式場景方案。 | MIT |

## API 資源

| API | 用途 | 免費/金鑰狀態 |
| --- | --- | --- |
| [Open-Meteo](https://open-meteo.com/en/docs) | 氣溫、降雨、天氣狀態與氣候壓力。 | 一般使用免費，通常不需金鑰。 |
| [Open-Meteo Flood API](https://open-meteo.com/en/docs/flood-api) | 河川流量與洪水時序，可用於洪水任務。 | 一般使用免費，通常不需金鑰。 |
| [NASA POWER](https://power.larc.nasa.gov/docs/services/api/) | 太陽輻射、氣溫、降雨與能源教育情境。 | 公開 API。 |
| [World Bank Indicators API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392) | 人口、都市化、能源、經濟、教育與健康背景資料。 | 公開 API，通常不需金鑰。 |
| [UNSD SDG API](https://unstats.un.org/SDGAPI/swagger/) | 永續發展目標官方指標、指標名稱與報告脈絡。 | 公開 API。 |
| [OpenAQ API](https://docs.openaq.org/about/about) | PM2.5、PM10、NO2 等空氣品質觀測。 | 免費帳號/API key；正式產品不應把 key 寫在前端。 |
| [USGS Earthquake GeoJSON](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php) | 未來災害擴充：地震任務事件。 | 公開資料。 |
